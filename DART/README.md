## Deskripsi Singkat Program
Program ini menghitung gaji bersih karyawan berdasarkan:
- Nama karyawan
- Jumlah jam kerja per minggu
- Upah per jam
- Status karyawan (tetap/kontrak)

Gaji kotor dihitung dari jam kerja dikali upah per jam.  
Pajak dipotong 10% untuk karyawan tetap, 5% untuk kontrak.  
Program menampilkan nama, gaji kotor, pajak, dan gaji bersih.
